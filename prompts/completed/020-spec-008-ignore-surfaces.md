# Read and parse a repo's ignore surfaces

<summary>
- The GitHub client can read any single file from a repo's default branch, returning "absent" for a 404 instead of an error, so a repo without an ignore file is not a failure.
- Four ignore files per repo are named in one exported list: `Makefile`, `Makefile.precommit`, `.trivyignore` and `.osv-scanner.toml`.
- One extractor recognises the three advisory ID families the fleet actually uses — `GO-YYYY-NNNN`, `CVE-YYYY-NNNN` and `GHSA-xxxx-xxxx-xxxx` — and de-duplicates them while keeping first-seen order.
- The `VULNCHECK_IGNORE` assignment is parsed correctly when it spans several lines with `\` continuations, which is the fleet's canonical form, and when it sits on one line.
- `.trivyignore` yields one ID per line, skipping comment lines, blank lines and trailing `# …` remarks.
- `.osv-scanner.toml` yields only the `id = "…"` values inside `[[IgnoredVulns]]` blocks, never an advisory-shaped string in a `reason`.
- A repo with no IDs on any surface produces an empty result rather than an error or a guess.
- Oversize files are refused before decoding, matching the existing `go.mod` cap, so an attacker-controlled ignore file cannot exhaust memory.
- Everything is covered by table-driven tests over committed fixtures taken from the real fleet files.
</summary>

<objective>
Give the watcher a read path for a repo's ignore surfaces and a parser per surface, so the stale-ignore pass can learn which advisories a repo suppresses without cloning it. This is the "what does this repo claim is safe" half of the signal; the OSV verdict half follows in the next prompt.
</objective>

### 1. Add `GetFile` to the `GitHubClient` interface in `pkg/githubclient.go`

Insert the method in the interface next to `GetGoMod` (order is cosmetic; keep `GetFile` after `GetGoMod`). Use exactly this doc comment and signature:

```go
	// GetFile returns the raw bytes of path at HEAD of repo's default branch.
	// Returns (nil, nil) when the file does not exist (HTTP 404) — an absent
	// ignore surface is empty, not an error. Returns (nil, ErrRateLimited) on
	// primary or abuse rate limiting. Every other failure (network, 5xx,
	// oversize, base64 decode) returns a wrapped error and drops the repo.
	GetFile(ctx context.Context, repo Repo, path string) ([]byte, error)
```

Implement it on `*githubClient` immediately after `GetGoMod`, mirroring `GetGoMod` line for line with two changes: the path comes from the argument instead of the literal `"go.mod"`, and the error messages name `path` and the repo:

```go
func (c *githubClient) GetFile(ctx context.Context, repo Repo, path string) ([]byte, error) {
	opts := &gogithub.RepositoryContentGetOptions{Ref: repo.DefaultBranch}
	fileContent, _, _, err := c.client.Repositories.GetContents(
		ctx, repo.Owner, repo.Name, path, opts,
	)
	if err != nil {
		if isNotFound(err) {
			return nil, nil
		}
		if isRateLimitError(err) {
			return nil, ErrRateLimited
		}
		return nil, errors.Wrapf(
			ctx, err, "get %s %s ref=%s", path, repo.String(), repo.DefaultBranch,
		)
	}
	if fileContent == nil {
		return nil, nil
	}
	if fileContent.GetSize() > maxContentBytes {
		return nil, errors.Errorf(
			ctx, "%s %s too large: %d bytes (max %d)",
			path, repo.String(), fileContent.GetSize(), maxContentBytes,
		)
	}
	decoded, err := fileContent.GetContent()
	if err != nil {
		return nil, errors.Wrapf(ctx, err, "decode %s %s", path, repo.String())
	}
	if len(decoded) > maxContentBytes {
		return nil, errors.Errorf(
			ctx, "%s %s decoded too large: %d bytes (max %d)",
			path, repo.String(), len(decoded), maxContentBytes,
		)
	}
	return []byte(decoded), nil
}
```

Do not add a retry, a timeout, or a context deadline here — the `http.Client` carries the timeout and the request carries the context, exactly as `GetGoMod` does. Do not change any other method or the `githubClient` struct.

`mocks/github_client.go` is generated: `make precommit`'s `generate` step deletes `mocks/` and regenerates it from the `//counterfeiter:generate` directive already above the interface, so `mocks.GitHubClient` gains `GetFile`, `GetFileReturns`, `GetFileCallCount` and `GetFileArgsForCall` automatically. ### 2. Create `pkg/ignore_surface.go` — package `pkg`, the surface list, the ID regex and the four parsers

The file holds exactly this surface (doc comments included; bodies are yours but must satisfy the rules in step 3):

```go
// IgnoreSurfaceFiles is the ordered list of repo files the stale-ignore pass
// reads from a repo's default branch. A missing file is an empty surface, not
// an error. Makefile and Makefile.precommit both carry the VULNCHECK_IGNORE
// assignment; .trivyignore and .osv-scanner.toml each carry their own format.
var IgnoreSurfaceFiles = []string{
	"Makefile",
	"Makefile.precommit",
	".trivyignore",
	".osv-scanner.toml",
}

// advisoryIDPattern matches the three advisory ID families the fleet's ignore
// surfaces carry: GO-YYYY-NNNN, CVE-YYYY-NNNN and GHSA-xxxx-xxxx-xxxx.
// Anchored on word boundaries and length-bounded so an attacker-controlled
// ignore file cannot make the parser allocate unboundedly.
var advisoryIDPattern = regexp.MustCompile(
	`\b(GO-\d{4}-\d{4,}|CVE-\d{4}-\d{4,}|GHSA(-[0-9a-z]{4}){3})\b`,
)

// ExtractAdvisoryIDs returns every advisory ID in text, de-duplicated, in
// first-seen order. It returns nil when text carries none.
func ExtractAdvisoryIDs(text string) []string

// ParseIgnoreSurface parses one ignore surface file by its path, returning the
// advisory IDs it declares. An unknown path, or an absent file, returns nil.
// Makefile and Makefile.precommit are parsed as VULNCHECK_IGNORE assignments,
// .trivyignore line-wise, .osv-scanner.toml as [[IgnoredVulns]] blocks.
func ParseIgnoreSurface(path string, content []byte) []string

// ParseVulncheckIgnore returns the advisory IDs in the first VULNCHECK_IGNORE
// assignment in a Makefile-style file, including a `\`-continued multi-line
// assignment. The assignment ends at the first line not ending in `\`.
func ParseVulncheckIgnore(content []byte) []string

// ParseTrivyIgnore returns the advisory IDs in a .trivyignore file: one ID per
// line, with `#` comment lines, blank lines and trailing `# …` remarks ignored.
func ParseTrivyIgnore(content []byte) []string

// ParseOsvScannerToml returns the advisory IDs declared by `id = "<ID>"` lines
// inside [[IgnoredVulns]] blocks of a .osv-scanner.toml file, and nothing else.
func ParseOsvScannerToml(content []byte) []string
```

`ParseIgnoreSurface` dispatches on `path`: `"Makefile"` and `"Makefile.precommit"` → `ParseVulncheckIgnore`; `".trivyignore"` → `ParseTrivyIgnore`; `".osv-scanner.toml"` → `ParseOsvScannerToml`; every other path → `nil`. Do not match on a suffix or a basename — the caller passes exactly the names in `IgnoreSurfaceFiles`.

### 3. Parser rules — these are the acceptance criteria, implement them exactly

**`ExtractAdvisoryIDs(text string) []string`**
- Apply `advisoryIDPattern` with `FindAllString`.
- De-duplicate by exact string equality, preserving first-seen order (`seen := map[string]struct{}{}` + append).
- Return `nil` (not an empty slice) when nothing matches.

**`ParseVulncheckIgnore(content []byte) []string`**
- Split on `\n`. For each line take `strings.TrimSpace(line)`.
- The assignment line matches `^VULNCHECK_IGNORE\s*\??=` — i.e. after trimming, the line starts with the literal `VULNCHECK_IGNORE`, then optional whitespace, then an optional `?`, then `=`. Both `VULNCHECK_IGNORE ?= …` and `VULNCHECK_IGNORE = …` match. A comment (`# VULNCHECK_IGNORE …`), a `$(VULNCHECK_IGNORE)` reference on another assignment, and a line such as `IGNORE_JSON=$$(printf … $(VULNCHECK_IGNORE) …)` must NOT match.
- Take the value as everything after the `?=`/`=` operator, then: while the trimmed value ends with `\`, drop that trailing `\`, append the next line, and continue. Stop at the first line that does not end with `\` (the last line of the file ends the assignment too).
- Return `ExtractAdvisoryIDs` of the assembled value.
- Only the FIRST matching assignment is used; return after it.
- No matching assignment → `nil`.

**`ParseTrivyIgnore(content []byte) []string`**
- Split on `\n`. For each line, cut at the first `#` (`strings.Cut`), trim space, skip when empty, then run `ExtractAdvisoryIDs` on the remainder and append.
- A line that is entirely a comment, or entirely blank, contributes nothing. An ID with a trailing `# reason` contributes the ID only.
- Return the concatenation, de-duplicated (re-run the de-duplication over the collected result, so the same ID on two lines appears once).

**`ParseOsvScannerToml(content []byte) []string`**
- Split on `\n`, walk line by line, tracking a boolean `inIgnoredVulns`.
- A trimmed line starting with `[[` sets `inIgnoredVulns = (trimmed == "[[IgnoredVulns]]")` and contributes nothing.
- Only while `inIgnoredVulns` is true, match the trimmed line against `^id\s*=\s*"([^"]*)"$`; on a match, append `ExtractAdvisoryIDs(match[1])`.
- A `reason = "…"` line is never matched, even when its text contains an advisory-shaped string. A bare `id =` line outside any `[[IgnoredVulns]]` block is never matched.
- Return the concatenation, de-duplicated.

Keep every function small enough for the linters (`.golangci.yml`: funlen 80 lines / 50 statements, gocognit 20, nestif 4, gocyclo default) — extract a `collectIDs(lines []string) []string`-style helper if a parser grows past that. Keep every line under 100 characters (`golines --max-len=100` runs in `make precommit`).
